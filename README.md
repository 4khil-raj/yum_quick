YumQuick – Food Delivery App
YumQuick is a Flutter food delivery app built as part of a Flutter Developer assignment. It lets users explore recipes, search and filter food, view recipe details, manage a cart, and complete a local order confirmation flow.
The project focuses on a clear feature-based structure, reusable Flutter widgets, and code that is easy to read and maintain.
Features
- Authentication: Login using the DummyJSON authentication API, with session persistence.
- Home and menu: Browse recipes and food categories.
- Search and filters: Search recipes and filter results using the available criteria.
- Recipe details: View recipe information and add items to the cart.
- Cart: Add or remove items, update quantities, and review the bill summary.
- Coupons and pricing: Apply supported coupon codes and view the calculated order total.
- Checkout: Review the order and complete the local order confirmation flow.
- Order history: View saved orders, where supported by the current implementation.
- Local storage and caching: Retain supported app data locally and cache recipe data for offline use.
- Loading and error states: Show feedback for loading, empty results, and errors.
The app uses DummyJSON recipe data. Recipes do not provide a real food-delivery price, so the app uses its own price calculation. The category mapping and pricing rules are demo rules, not live restaurant pricing.

Tech Stack
- Flutter and Dart
- BLoC for application state management
- Dio for HTTP requests
- DummyJSON API for authentication and recipe data
- Hive for supported local storage and caching
- flutter_secure_storage for authentication tokens
- GoRouter for navigation
API
The app uses the DummyJSON API:
- Login: POST https://dummyjson.com/auth/login
- Recipes: GET https://dummyjson.com/recipes
- Recipe search: GET https://dummyjson.com/recipes/search?q=<query>
For testing the login flow, DummyJSON documents the sample account:

Pricing and Category Notes
DummyJSON recipe data is not a live restaurant menu and does not include delivery prices. YumQuick applies demo pricing and local cart rules for the assignment.
- Recipe prices are generated by the app rather than supplied by DummyJSON.
- Recipe categories are mapped from the API's available meal types and tags.
- Taxes, delivery charges, platform fees, and coupon discounts are handled by the app's pricing logic.
- Checkout and order confirmation are part of the app's local demo flow; this is not a real payment integration.
Refer to the relevant pricing and category-mapping code for the exact rules used by this version of the project.
Getting Started
Requirements
Install Flutter and the platform tools required for the device you plan to use.
Check your Flutter setup:
flutter doctor
Install dependencies
Clone the repository, open the project directory, and run:
flutter pub get
Run the app
flutter run
Run static analysis
flutter analyze
Run tests
flutter test
Build an Android APK
flutter build apk --release
If the build succeeds, the APK is normally generated at:
build/app/outputs/flutter-apk/app-release.apk
Testing
The project includes unit and widget tests for parts of the app, such as repository behavior, cart pricing, search state, and UI components.
Run the full test suite with:
flutter test
Run the analyzer with:
flutter analyze
Record the results from the current checkout when submitting the project. Test counts and build results can change as the code changes, so they should only be reported after running the commands.

Notes and Limitations
- This is an assignment/demo application, not a production food-delivery service.
- Recipe data comes from DummyJSON and may not represent real restaurant availability.
- Prices and category assignments are demo rules created by the app.
- Checkout confirms the order locally; no real payment is processed.
- Offline support depends on which data has already been cached and which features are available without a network connection.
- Authentication behavior depends on DummyJSON and the app's current session-handling implementation.
